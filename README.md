# 智洁环控 — 智能垃圾环保监控系统

> 2024 年华北五省及港澳台大学生计算机应用大赛参赛作品（天津赛区 · 天津理工大学）

## 项目简介

基于 YOLOv10 目标检测 + LSTM 时序预测的智能垃圾桶管理系统，涵盖 Web 端、App 端、后端服务、物联网终端及检测算法，实现对垃圾桶的实时监控、自动分类、异常报警和数量预测。

## 系统架构

| 模块 | 技术栈 |
|------|--------|
| **Web 前端** | Vue 3 + TypeScript + Vite + Element Plus |
| **App 前端** | uni-app (Android) |
| **后端服务** | Spring Boot 3 + MyBatis + MySQL + MQTT |
| **检测算法** | YOLOv10 (GSConv 改进) + ConvLSTM |
| **物联网终端** | STM32F103 + ESP32-CAM + OV2640 |
| **传感器** | 超声波测距、MQ-2 烟雾、MQ-4 甲烷、人体红外 |

## 核心功能

- **垃圾自动分类**：摄像头采集图像 → YOLOv10 识别 → 对应桶盖自动开启，分类准确率 >90%
- **实时数据监控**：传感器数据经 MQTT 上报至后端，Web/App 端可视化展示
- **异常报警**：烟雾/甲烷超标自动告警，垃圾桶溢满提醒
- **数量预测**：基于 LSTM 的垃圾投放量趋势预测与风险预警
- **路径规划**：地图标注垃圾桶位置，规划清运路线
- **低功耗**：人体红外感应唤醒，无人员时自动待机
